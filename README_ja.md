# miditrack

NES（`.nsf`）、SNES（`.spc`/`.rsn`）、VGM（`.vgm`/`.vgz`）のチップチューン音楽を、ブラウザだけで楽器を差し替え・リミックス・書き出しできるMIDIファイルに変換します。日常的な利用にターミナルは不要です。

`miditrack`はローカルで動くWebアプリで、チップチューンの音源ファイルをMIDIに変換し、各トラックにGeneral MIDIの楽器と音量を割り当て、その場で試聴できます。汎用シンセの代わりに実機・原曲のチップサウンドを鳴らすオプションも備えています。内部では3つのバンドル済みコマンドラインコンバーター（`nsf2midi`・`spc2midi`・`vgm2midi`）と2つの共有スクリプト（`midi2wav.sh`・`pitch_shift.sh`）が動いており、ブラウザ操作よりスクリプトを好む場合はこれらを単体でターミナルから使うこともできます。

## クイックスタート

1. **必要なものをインストール**（macOS専用）:
   ```bash
   brew install fluid-synth
   ```
   General MIDI SoundFont（`.sf2`/`.sf3`）も`miditrack`が見つけられる場所に用意してください。詳細は下記の[必要環境](#必要環境)を参照。
2. **`miditrack`をセットアップ**（初回のみ）:
   ```bash
   cd miditrack
   python3 -m venv .venv
   .venv/bin/python -m pip install --upgrade pip
   .venv/bin/python -m pip install -e .
   ```
3. **起動する**:
   ```bash
   ./miditrack.sh
   ```
   自動的にブラウザタブが開きます。`ln -s "$PWD/miditrack.sh" /opt/homebrew/bin/miditrack` で一度だけPATHにシンボリックリンクを作っておけば、以後はどこからでも`miditrack`と入力するだけで起動できます。
4. **ファイルをドロップ** — `.nsf`、`.spc`、`.rsn`、`.vgm`/`.vgz`、または変換済みの`.mid`をアップロード領域に置きます。
5. **変換して試聴、ダウンロード** — 複数曲を含むファイルなら曲を選び、音源ファイルから始めた場合は「MIDIに変換」をクリック、続いて「適用して試聴」で試聴し、満足したら`.mid`または`.wav`をダウンロードします。

## できること

- **チップチューンファイルをそのままMIDIに変換** — `.nsf`/`.spc`/`.rsn`/`.vgm`（およびそのバリエーション）を、`.mid`と同じアップロード領域にドロップするだけ。複数曲を含む形式（NSF、SPC）では、変換したい曲を選べます。
- **リップパック一式をまとめてアップロード** — 複数の音源ファイルを含む`.zip`や、複数ファイルの同時選択も、展開の手間なくそのまま扱えます。同梱された`.m3u`プレイリストは自動的に読み込まれ、単なるトラック番号ではなく実際の曲名を表示します。
- **各トラックの楽器を差し替え** — すべてのトラックにGeneral MIDI楽器のドロップダウンがあり、16の標準ファミリー（ピアノ、ギター、ストリングス、ブラスなど）にグループ化されているので選びやすくなっています。コンバーターがすでに選んでいた楽器は初期選択済みです。
- **トラックごとに音量を調整** — 0〜200%のスライダーが各トラックに用意されており、複数のトラックが同じMIDIチャンネルを共有していても互いに影響しません。
- **汎用SoundFontの代わりに原曲のチップ・実機サウンドを鳴らす** — 対応するトラックでは「SoundFont」の行を「原曲の音源」に切り替えることで、合成音の近似ではなく実際のNES/SNES/チップハードウェアの出力を聴くことができます。
- **曲全体の速度とピッチを変更** — 「WAVをダウンロード」の横にある簡易な−／＋コントロールで、全体の速度倍率と半音単位のトランスポーズを調整できます。変更はMIDIに直接反映され（音声のタイムストレッチによる劣化なし）、元に戻すまで再生・WAVダウンロード・MIDIダウンロードすべてに適用されます。
- **速度・ピッチのバリエーションを一括書き出し** — 普段は閉じている「バリエーションをまとめて生成」のディスクロージャを開くと、複数の速度倍率と半音シフトのすべての組み合わせを、1つのダウンロード可能なWAV群のZIPとして生成できます。ゲーム開発やリミックス用途に便利です。
- **試聴とダウンロード** — シーク・スクラブ対応のオーディオプレーヤーに加え、編集済みの`.mid`と描画済みの`.wav`の両方をダウンロードするボタンがあります。アップロードした元ファイルが書き換えられることはありません。
- **好きなSoundFontを選択** — レンダリングに使う`.sf2`/`.sf3`バンクをブラウザから選べます。

すべての処理はお使いのマシン上でローカルに行われ、ファイルが外部にアップロードされることはありません。

## ツール構成の全体像

| ツール | 何をするか | 使い方 |
|---|---|---|
| **miditrack** | 上記のWebアプリ本体 — このツールキットの推奨の使い方 | ブラウザ（`miditrack.sh`/`miditrack`経由） |
| **nsf2midi** | NES/ファミコンの`.nsf`/`.nsfe`ファイルをMIDIに変換 | miditrackに内蔵、またはターミナルから直接 |
| **spc2midi** | SNESの`.spc`/`.spc2`/`.rsn`ファイルをMIDIに変換（対応するSoundFontも生成可） | miditrackに内蔵、またはターミナルから直接 |
| **vgm2midi** | VGM/VGZコマンドログファイル（メガドライブ、アーケード、PC-88など）をMIDIに変換 | miditrackに内蔵、またはターミナルから直接 |
| **midi2wav.sh** | fluidsynthを使い、任意の`.mid`ファイルを試聴用`.wav`に変換 | 上記4つのツールから自動的に呼び出される、または単体で直接実行 |
| **pitch_shift.sh** | 音声ファイルの速度・ピッチのバリエーションをWAVとして生成 | miditrackのZIP書き出し機能から自動的に呼び出される、または単体で直接実行 |

ほとんどの場合は`miditrack`だけで十分です。3つのコンバーターと2つのスクリプトはその構成要素として存在していますが、ブラウザ操作よりスクリプトによる変換パイプラインを組みたい場合は、それぞれ単体でも動作します。

## 必要環境

- macOS
- Python 3.10以上（`miditrack`本体用）
- [fluidsynth](https://www.fluidsynth.org/) — `brew install fluid-synth`
- General MIDI SoundFont（`.sf2`/`.sf3`）。`MIDI2WAV_SOUNDFONT`環境変数でパスを指定するか、以下のいずれかの場所に置けば自動的に見つかります:
  - `<このリポジトリ>/soundfonts`
  - `~/Library/Audio/Sounds/Banks`
  - `/opt/homebrew/share/soundfonts`
  - `/Library/Audio/Sounds/Banks`
  - `/opt/homebrew/share/fluid-synth/sf2`
- 3つのコンバーター（`nsf2midi`・`spc2midi`・`vgm2midi`）は、このリポジトリにビルド済みでバンドルされており、通常の利用では別途ビルドは不要です。
- VGMトラックの原曲の音源を試聴するには、バンドルされたネイティブヘルパーを一度だけビルドしてください（`cd vgm2midi && ./scripts/build-native.sh`）。NSFの原曲の音源には別途のビルド手順は不要です。
- 実機ノイズのミキシング、速度・ピッチバリエーションZIPの書き出し、非デフォルトの速度・ピッチにチップノイズのステムを同期させる場合: [ffmpeg](https://ffmpeg.org/)と[rubberband-cli](https://breakfastquay.com/rubberband/) — `brew install ffmpeg rubberband`。

## miditrackの使い方

### MIDIファイルから始める場合

1. `.mid`/`.midi`ファイルを選択またはドラッグしてアップロード領域に置きます。
2. トラック一覧が表示されます。編集可能な各トラックには楽器のドロップダウン（ファイルにすでに指定されている楽器が初期選択済み）が、ノートを持つトラックには0〜200%の音量スライダーが表示されます。長いトラック名や変更不可理由は行高を揃えるため「…」で省略され、楽器変更の警告は⚠へポインターを合わせるかフォーカスすると全文を確認できます。
3. 試聴カードの**SoundFont**ドロップダウンで、必要に応じて別のSoundFontを選びます。
4. 「WAVをダウンロード」の横にある簡易な−／＋コントロールで、必要に応じて速度倍率や半音単位のトランスポーズを調整します。中央の数値欄へ直接入力することもできます。
5. 「適用して試聴」をクリックして描画し、オーディオプレーヤーを使います — スクラバーをドラッグすると自由にシークできます。
6. 「MIDIをダウンロード」または「WAVをダウンロード」をクリックして成果物を保存します。
7. 必要に応じて「バリエーションをまとめて生成」を開き、カンマ区切りの速度倍率・半音値を入力して「バリエーションをZIPでダウンロード」をクリックすると、すべての組み合わせを1つのZIPとして取得できます。

### 音源ファイル（`.nsf`/`.spc`/`.rsn`/`.vgm`、`.zip`、または複数ファイル）から始める場合

1. ファイルをアップロード領域にドロップします — 単一の音源ファイル、`.m3u`プレイリストを伴う音源ファイル、または複数の音源ファイルを含む`.zip`アーカイブのいずれでも構いません。miditrackが形式を自動検出し、複数曲に対応する形式（NSF、SPC）では曲を一覧表示して選べるようにします。
2. 変換可能なファイルが複数見つかった場合は、**ファイル**ドロップダウンでどれを使うか選びます。
3. 曲を選択（対応形式の場合）し、その形式固有のオプションを調整します — NSFなら再生時間・PALタイミング、SPCならループ回数、VGMならテンポ・ループ・再生時間。NSFとVGMには、汎用ドラムキットの代わりに実機のパーカッションサウンドをそのまま残す「chip noise」オプションもあります。
4. 「MIDIに変換」をクリックします。以降は`.mid`を直接アップロードした場合と同じようにトラック一覧が表示されるので、上記の手順を続けてください。
5. 再度変換する（別の曲、別のファイル、別のオプション）と、`.mid`を再アップロードした場合と同様に、現在のトラック編集内容と描画済みの音声は破棄されます。

### 原曲の音源とSoundFontの違い

実機・原曲のサウンドで再生できるトラックでは、Sourceドロップダウンで2つの選択肢が表示されます:

- **原曲の音源** — トラックが実際のチップエミュレーション（NSF、VGM）またはゲーム自身のサンプルから生成したSoundFont（SPC）を通じて再生され、汎用シンセの代わりに使われます。**（推奨）**と表示されている行は、切り替えても安全だと自動的に判定されたものです。
- **SoundFont** — トラックが選択中のGeneral MIDI SoundFontを通じて再生され、楽器ドロップダウンを自由に変更できます。

原曲の音源に切り替えると、VGM/NSFのトラックでは楽器ドロップダウンが無効になります（その音声はSoundFontを一切経由しないためです）。SPCの場合は楽器の操作のみが無効になり、音量調整は引き続き有効です。

### コマンドラインオプション

```
miditrack [MIDI_FILE] [--soundfont FILE] [--no-browser]
```

| オプション | 説明 |
|---|---|
| `MIDI_FILE` | ブラウザ起動時にプリロードする`.mid`/`.midi`ファイル（任意）。音源ファイルはブラウザからアップロードする必要があります。 |
| `-s, --soundfont FILE` | 起動時のデフォルトSoundFont。ブラウザからいつでも変更できます。 |
| `--no-browser` | ブラウザタブを自動的に開かない。 |
| `--version` | バージョンを表示して終了する。 |

## コンバーターを直接使う

ブラウザ操作の代わりに変換をスクリプト化したい場合、各コンバーターは単体のコマンドとしても動作します。オプションの全リストや例は各ツール自身のREADMEを参照してください。以下は日常的によく使うケースの要約です。

### nsf2midi（NES）

```bash
nsf2midi song.nsf song.mid          # 変換
nsf2midi -l song.nsf                # ファイル内の曲・トラックを一覧表示
nsf2midi --wav song.nsf song.mid    # .wavも同時に描画
```

`.mdf`ファイルによる楽器のカスタマイズ、PALタイミング、実機チップ音声の描画については[nsf2midi/README.md](nsf2midi/README.md)を参照してください。

### spc2midi（SNES）

```bash
spc2midi song.rsn song.mid              # 変換（.spc/.spc2/.rsnを自動判定）
spc2midi -l song.rsn                    # ファイル内のシーケンスを一覧表示
spc2midi -s 12 --sf2 song.rsn song.mid  # 1曲を変換し、対応するSoundFontも生成
```

複数曲を含む`.rsn`アーカイブ、SoundFont/DLS書き出し、ループの展開については[spc2midi/README.md](spc2midi/README.md)を参照してください。

### vgm2midi（メガドライブ、アーケード、PC-88など）

```bash
vgm2midi song.vgz                       # 変換（song.midを生成）
vgm2midi song.vgz -v                    # 詳細表示：検出されたチップを表示
vgm2midi song.vgz --loops 3             # ループ部分を合計3回再生
```

対応する音源チップの一覧や高度なオプションについては[vgm2midi/README.md](vgm2midi/README.md)を参照してください。

### midi2wav.sh（任意のMIDIをWAVに描画）

```bash
./midi2wav.sh song.mid                  # デフォルトSoundFontで描画
./midi2wav.sh -S song.mid               # SoundFontを対話選択
./midi2wav.sh -s MySound.sf2 -f song.mid  # SoundFontを指定し、既存の出力を上書き
```

### pitch_shift.sh（速度・ピッチのバリエーションを一括生成）

```bash
./pitch_shift.sh song.m4a                          # 10ファイル：速度2種×ピッチ5種（デフォルト）
./pitch_shift.sh -s 1.5 -p -3 -p -5 song.m4a        # 速度x1.5、ピッチ2種＝2ファイル
```

ローカルの音声ファイルに加えて、URL（`yt-dlp`経由でYouTubeも含む）も指定できます。

## トラブルシューティング

- **「SoundFont not found」** — `--soundfont`を明示的に指定するか、`MIDI2WAV_SOUNDFONT`環境変数を設定するか、[必要環境](#必要環境)に記載のディレクトリのいずれかに`.sf2`を配置してください。
- **「midi2wav not found」** — `fluidsynth`がインストールされているか確認してください（`brew install fluid-synth`）。
- **「nsf2midi/spc2midi/vgm2midi not found」** — これらはこのリポジトリにビルド済みで同梱されているため、通常は発生しません。移動または再ビルドした場合は、通常のパスに戻すか、対応する`NSF2MIDI_BIN`/`SPC2MIDI_BIN`/`VGM2MIDI_BIN`環境変数を設定してください。
- **「対応するSNESサウンドドライバが見つかりませんでした」** — `.spc`ファイルの音楽ドライバが`spc2midi`が認識する約20種類のいずれにも該当しません。このファイルは変換できません。
- **「対応する音源ファイルが見つかりません」** — アップロードされたファイルのいずれも対応拡張子に一致しませんでした。
- **「有効なZIPファイルではありません」** — アップロードした`.zip`が破損しているか、実際にはZIPではありません。
- **「miditrack requires Flask」** — 上記の[クイックスタート](#クイックスタート)の手順に従って`.venv`を作り直してください。
- **「pitch_shift.sh が見つかりません」** — `ffmpeg`と`rubberband-cli`がインストールされているか確認してください（`brew install ffmpeg rubberband`）。
- **「速度×ピッチの組み合わせ数が多すぎます」** — ZIP書き出し機能で指定する速度・ピッチの数を減らしてください（上限は40組み合わせです）。

## 謝辞

このツールキットは、いくつもの優れたオープンソースプロジェクトの上に成り立っています。

- **[NotSoFatso](https://github.com/BleuBleu/FamiStudio)**（Disch氏作） — `nsf2midi`がAPUおよび拡張音源チップをエミュレートするためにバンドルしているNES/ファミコン再生コア。FamiStudioプロジェクトによる現代的な移植版から取り込んでいます。
- **オリジナルの`nsf2midi.exe` 0.14** — ソースコードもコマンドラインインターフェースも公開されていないWindows GUIツール。本リポジトリの`nsf2midi`は、同じ`.mdf`楽器定義フォーマットを読み込めるように、macOS/arm64向けにゼロから再実装したものです。
- **[VGMTrans](https://github.com/vgmtrans/vgmtrans)** — `spc2midi`は、ノート検出をゼロから実装するのではなく、VGMTransが持つドライバ別のSNESシーケンスパーサーの上に直接構築されています。
- **[jkarenko/vgm2midi](https://github.com/jkarenko/vgm2midi)** — `vgm2midi`はこのプロジェクトのフォークとして始まり、いくつかの音源チップ対応とバグ修正を加えて拡張したものです。
- **[FluidSynth](https://www.fluidsynth.org/)** — `midi2wav.sh`がすべてのWAV試聴・ダウンロードを描画する際に使うSoundFontシンセサイザー。
- **[Rubber Band Library](https://breakfastquay.com/rubberband/)**（`rubberband-cli`経由） — `pitch_shift.sh`が速度・ピッチのバリエーションを生成するために使うタイムストレッチ・ピッチシフトエンジン。

詳細なクレジットとライセンスについては、各サブプロジェクト自身の`README.md`/`NOTICE.md`を参照してください。
